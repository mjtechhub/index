OSPF Basics

OSPF (Open Shortest Path First) is a link-state Interior Gateway Protocol used heavily in enterprise networks.

How OSPF Works

Unlike simple distance-vector protocols, OSPF routers build a complete topological map of the network (the link-state database) by exchanging link-state advertisements (LSAs). Each router then runs the Shortest Path First (SPF) algorithm, also known as Dijkstra's algorithm, to calculate the best paths to all destinations within its autonomous system.

Key Concepts

  • Autonomous System Context: OSPF operates within a single routing domain (Interior Gateway Protocol).
  • Areas: OSPF uses a hierarchical design. All areas must connect to the backbone area, known as Area 0.
  • Neighbors and Adjacency: Routers discover each other via Hello packets. Once they agree on parameters, they form an adjacency and exchange link-state information.
  • Cost / Metric: OSPF path selection is determined by cost. It does NOT automatically choose the path with the fewest routers. Cost is typically derived from interface bandwidth, though vendors calculate default interface costs differently.
  • Route Convergence: When a link fails, OSPF quickly floods the updated state to all routers, which recalculate their SPF trees, resulting in fast convergence.

Simple Topology Example

   Router A
      |
   Router B
  /        \
R-C       R-D

If R-C and R-D both connect to the same destination network, Router B will select the path with the lowest cumulative OSPF cost.

OSPFv2 vs OSPFv3

OSPFv2 is typically used for IPv4 routing. OSPFv3 was originally designed to support IPv6, but has evolved to support multiple address families (both IPv4 and IPv6) within its modern framing.
