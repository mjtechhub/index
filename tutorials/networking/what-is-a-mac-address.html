What Is a MAC Address?

Learn about the 48-bit physical address used in Layer 2 networks.

A MAC (Media Access Control) Address is a unique hardware identifier burned into the network interface controller (NIC) of every networked device. Whether it's an Ethernet port on a server, a Wi-Fi chip in a smartphone, or a Bluetooth adapter in headphones, every physical network interface requires a unique MAC address to communicate.

MAC Address vs IP Address

To understand networking, you must understand the difference between these two addresses:

  • An IP Address is logical, software-based, and changes depending on what network you connect to (like a mailing address for a house). It is used for end-to-end routing across the internet.
  • A MAC Address is physical, hardware-based, and generally permanent (like a vehicle's VIN number). It is used only for local communication on the same physical network or VLAN.

Common MAC Address Notation

A MAC address is a 48-bit value, represented as 12 hexadecimal digits. Depending on the operating system or hardware vendor, it can be displayed in slightly different formats:

  • Windows format: 00-1A-2B-3C-4D-5E
  • Linux / macOS format: 00:1a:2b:3c:4d:5e
  • Cisco switch format: 001a.2b3c.4d5e

The first half of the address (24 bits) is the OUI (Organizationally Unique Identifier), which identifies the hardware manufacturer (e.g., Apple, Dell, Cisco). The second half is a unique serial number assigned by that manufacturer.

How Switches Use MAC Addresses

Unlike routers which read IP addresses, standard Layer 2 network switches do not care about IP addresses. They make all their forwarding decisions based strictly on MAC addresses.

When a switch is powered on, its MAC address table is empty. As devices connect and send data, the switch looks at the Source MAC Address of the incoming Ethernet frame and records which physical port that MAC address is plugged into.

When the switch needs to forward a frame to a specific destination, it checks its MAC address table. If it knows which port the destination MAC is on, it sends the frame only out of that port (Unicast). If it doesn't know, it floods the frame out of all ports (Broadcast) until it learns the location. You can read more in Unicast vs Broadcast vs Multicast.

MAC Randomization (Privacy Feature)

Historically, a MAC address was permanently burned into the hardware. Because mobile devices broadcast their MAC addresses while searching for Wi-Fi networks, retail stores and advertisers used MAC tracking to follow users physically around a mall or city.

To combat this, modern iOS, Android, and Windows devices implement MAC Randomization. When connecting to a public Wi-Fi network, the device generates a fake, random MAC address rather than revealing its true hardware address. This protects user privacy but can frustrate network administrators trying to enforce MAC-based access controls or captive portals.

Commands to Find Your MAC Address

Windows

Use the ipconfig /all command to view detailed network information. The MAC address is listed as the Physical Address.

> ipconfig /all

Ethernet adapter Local Area Connection:
  Description . . . . . . . . . . . : Intel(R) Gigabit Network Connection
  Physical Address. . . . . . . . . : 00-1A-2B-3C-4D-5E

Linux

Use the ip link command. The MAC address is listed next to link/ether.

$ ip link show eth0
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc pfifo_fast state UP mode DEFAULT group default qlen 1000
    link/ether 00:1a:2b:3c:4d:5e brd ff:ff:ff:ff:ff:ff

Common Troubleshooting Scenarios

1. The Wrong Interface MAC

Problem: A network administrator sets up a DHCP reservation or firewall rule allowing a specific server based on its MAC address. However, the server cannot connect.

Troubleshooting: Modern servers and laptops often have multiple network interfaces (e.g., Wi-Fi, Ethernet, VPN virtual adapters, or Docker bridge networks). The administrator likely copied the MAC address for the Wi-Fi adapter, but the server is currently plugged in via the physical Ethernet port. Always ensure you are looking at the active interface's physical address.

2. MAC Address Filtering Failures

Problem: A home or corporate Wi-Fi network uses MAC filtering (whitelisting only known devices). A user upgrades to a new iPhone, and despite having the correct Wi-Fi password, they cannot connect.

Troubleshooting: Because of MAC Randomization, the new iPhone is presenting a random, unrecognized MAC address to the router. The user must disable "Private Wi-Fi Address" for that specific corporate network to reveal their true MAC, which the administrator can then whitelist.

Quick Summary

  • A MAC address is a physical hardware identifier used for local network communication.
  • ARP is used to link logical IP addresses to physical MAC addresses.
  • Switches use MAC addresses to forward traffic directly to the correct port.
  • Modern mobile devices randomize their MAC addresses for privacy on public networks.
