What Is Routing?

Routing is the process of moving network packets from one IP network to another. When you send data over the internet or across different subnets in an office, routing determines the exact path the packets will take to reach their final destination.

Local Subnet vs Remote Subnet

Before a device sends out a packet, it determines if the destination is on the local subnet or a remote subnet by checking its own IP address and Subnet Mask.

  • Local Subnet: If the destination is on the same subnet, the device communicates directly using MAC addresses (Layer 2) via Switches.
  • Remote Subnet: If the destination is on a different subnet, the packet must be sent to the Default Gateway. The gateway is a Router or Layer 3 Switch responsible for handling traffic leaving the local network.

How Layer 3 Forwarding Works

A Router operates at Layer 3 (Network Layer) of the OSI model. When a packet arrives, the router inspects the Destination IP address inside the packet header. It does not route traffic based on MAC addresses, because MAC addresses are only significant on the local network segment (Layer 2).

The router then consults its Routing Table—a map of known networks—to find the best path. If a match is found, the router forwards the packet to the appropriate interface or the next hop (the next router in the path). If there is no specific match, the router usually sends it to a default route.

A Practical Routing Example

Let's consider a practical scenario:

  • PC IP Address: 192.168.10.25/24
  • PC Default Gateway: 192.168.10.1
  • Destination IP: 10.20.30.50

Because the destination (10.20.30.50) is completely different from the PC's network (192.168.10.0/24), the PC knows the destination is on a remote subnet. The PC does not know how to reach 10.20.30.50 directly, so it simply sends the packet to its Default Gateway (192.168.10.1). The router takes over from there, making the forwarding decisions hop-by-hop until the packet arrives.

Viewing Routing Information

You can view your device's routing table using built-in commands:

Windows:

route print
Get-NetRoute

Linux:

ip route
