Remote Access VPN Explained

A Remote Access VPN allows an individual remote user or device to connect securely over the Internet to a private network, granting them access to internal resources as if they were physically in the office.

How It Works

The remote device runs VPN client software (or uses built-in OS capabilities). Upon successful authentication, a secure tunnel is established to the corporate VPN gateway. The gateway assigns the client a Virtual IP address from an internal pool, and injects routing instructions so the client knows how to reach the private network.

Full Tunneling vs Split Tunneling

  • Full Tunneling: All traffic from the remote device, including general Internet browsing, is forced down the VPN tunnel to the corporate network. This allows the organization to inspect and filter all traffic for security, but requires significant bandwidth.
  • Split Tunneling: Only traffic destined for the specific corporate subnets goes through the VPN. General Internet traffic goes directly out the user's local ISP connection. This saves corporate bandwidth but reduces visibility into the user's general web activity.

Protocols: IPsec vs TLS/SSL

Remote Access VPNs conceptually differ in underlying technology:

  • IPsec-based: Typically requires a dedicated software client and relies on standard IPsec negotiation.
  • TLS/SSL-based: Often relies on the same encryption protocols that secure HTTPS websites. Note that while historically called "SSL VPNs," modern secure implementations universally use TLS, as SSL is obsolete.

Security Best Practices

Because remote devices operate in untrusted environments, strict security is required:

  • Always mandate Multi-Factor Authentication (MFA).
  • Utilize Device Posture concepts (checking if the client has updated antivirus and patches before allowing connection).
  • Enforce the principle of Least Privilege (do not give remote users access to the entire network if they only need one server).
  • Patch VPN gateways immediately, as they are high-value targets. Disable obsolete cryptography.
  • Maintain thorough logging of connections and internal DNS queries.
