BGP Basics

BGP (Border Gateway Protocol) is the protocol that makes the Internet work. It is designed to exchange routing and reachability information between different Autonomous Systems (AS).

Autonomous Systems and eBGP/iBGP

  • Autonomous System (AS): A network or group of networks under a single administrative domain, identified by a unique ASN (Autonomous System Number).
  • eBGP (External BGP): Used to exchange routing information between different Autonomous Systems.
  • iBGP (Internal BGP): Used to exchange BGP information within the same Autonomous System, often to transit internet routes across a provider's backbone without redistributing them into the interior gateway protocol.

BGP Path Attributes

BGP does not simply use "cost" or "shortest path routing" (like OSPF). Instead, it uses a complex set of path attributes to determine the best route.

  • AS_PATH: The sequence of ASNs a route has traversed. While BGP prefers a shorter AS_PATH, it is only one part of the best-path decision process.
  • NEXT_HOP: The IP address of the next router to reach the destination. In BGP, this is often the IP of the eBGP peer, not necessarily the immediate connected router.
  • LOCAL_PREF: A conceptual attribute used within an AS to tell all internal routers which outbound path is preferred for a given prefix. Higher LOCAL_PREF wins.

BGP Use Cases

BGP is not for small, single-connection home networks. It is commonly used for Internet routing, multi-homed organizations (connecting to multiple ISPs for redundancy), service providers, and large-scale routing policy enforcement. BGP does NOT automatically choose the lowest-latency route; it chooses paths based on policy.
