DNS Troubleshooting Guide

Intermediate 8 min read

If a user complains that "the internet is down," but they can reach internal servers by IP address, they are likely experiencing a DNS (Domain Name System) resolution failure. Follow this practical troubleshooting sequence to isolate and resolve DNS issues.

Troubleshooting Sequence

1. Verify IP Configuration & DNS Server

Check if the device has a valid IP address and see which DNS servers it is currently using.

ipconfig /all

Important Note for Active Directory: Do not recommend setting public DNS (like 8.8.8.8) blindly on domain-joined Windows clients. AD clients rely heavily on the internal Domain Controller DNS to find domain services.

2. Test IP Connectivity vs Hostname Resolution

Try to ping an IP address directly (e.g., a known public IP like 1.1.1.1), and then ping a hostname (like example.com).

ping 1.1.1.1
ping example.com

If the IP ping succeeds but the hostname ping fails ("Ping request could not find host"), you have a confirmed name-resolution issue. Note that ping itself is not a definitive DNS troubleshooting tool, but it is a quick indicator.

3. Query DNS Directly

Bypass the ping command and ask the DNS server directly to resolve a name.

nslookup example.com

You can also use PowerShell:

Resolve-DnsName example.com

4. Test Alternative DNS Servers

If the default DNS server is failing, test against a different one explicitly to see if the issue is local to that specific server.

nslookup example.com 8.8.8.8

If this succeeds, your local DNS server might be down, misconfigured, or unreachable.

5. Check the DNS Cache

Sometimes the operating system caches a bad or outdated IP address. You can view the local DNS cache in Windows and clear it if necessary.

ipconfig /displaydns
ipconfig /flushdns

6. Server-Side Verification

If you control the DNS records and they recently changed, verify that you entered the correct A, CNAME, or MX records on your DNS provider's dashboard. Remember that global DNS propagation can sometimes take time, although modern systems often update very quickly.
