Routing Table Explained

Beginner / Intermediate 6 min read

A routing table is an internal database maintained by a router (or a computer) that tells it how to forward IP packets. When a packet arrives, the router looks up the destination IP address in this table to determine the best path to send the data.

Understanding Routing Table Fields

While the output format varies between Windows, Linux, and network switches, routing tables generally contain the following key fields:

  • Destination / Network Prefix: The target network or IP address range.
  • Prefix Length (or Netmask): Specifies how large the network is (e.g., /24 or 255.255.255.0).
  • Next Hop / Gateway: The IP address of the next router in the path to the destination.
  • Interface: The physical or virtual network interface used to send the packet out (e.g., eth0 or GigabitEthernet0/1).
  • Metric: A cost value representing the "distance" or preference for this route. Lower metrics are preferred.

Types of Routes

  • Connected Route: Networks directly attached to the router's own interfaces (e.g., 192.168.10.0/24 directly connected).
  • Specific Route: A route added manually (static) or dynamically for a specific destination network (e.g., 10.20.0.0/16).
  • Default Route (0.0.0.0/0): The "catch-all" route used when the router does not have a more specific match for the destination. This is essentially the default gateway.

The Longest Prefix Match Rule

One of the most critical concepts in routing is that more-specific prefixes are preferred over less-specific prefixes.

When a router examines its table, it looks for the longest matching prefix (the most specific match). For example, if a router receives a packet for 10.20.30.50 and its routing table contains both:

  • 10.20.30.0/24 (very specific)
  • 10.20.0.0/16 (less specific)
  • 0.0.0.0/0 (default route)

The router will choose the 10.20.30.0/24 route because it is the most specific match. Longest prefix match occurs before route metric is relevant. The metric is only used as a tie-breaker if there are multiple identical routes with the exact same prefix length.

Viewing the Routing Table

You can inspect the routing table on end devices using these commands:

Windows:

route print
Get-NetRoute

Linux / macOS:

ip route
