Spanning Tree Protocol (STP) Explained

Intermediate 6 min read

The Spanning Tree Protocol (STP) is a critical Layer 2 network protocol designed to prevent loops in Ethernet networks that have redundant links.

The Danger of Layer 2 Loops

Redundancy is good for reliability, but without STP, plugging switches into each other in a loop is disastrous. Ethernet frames do not have a "Time to Live" (TTL) mechanism like IP packets. If a loop exists:

  • Broadcast Storms: A single broadcast frame will circulate infinitely, multiplying and completely overwhelming network bandwidth and CPU resources.
  • Duplicate Frames: End devices will receive the exact same frame multiple times.
  • MAC Table Instability: Switches will constantly see the same MAC address arriving on different ports, causing the MAC address table to rapidly flap and break connectivity.

How STP Works Conceptually

STP mathematically transforms a physical loop into a logical tree topology by systematically blocking certain ports. The core concepts are:

  • Root Bridge: One switch is elected as the "king" of the network (based on the lowest Bridge ID). All other switches map their shortest path to this Root Bridge.
  • Bridge ID: A combination of a priority value and the switch's MAC address used during the election process.
  • Path Cost: A value assigned to each link (usually based on link speed) to determine the best route to the Root Bridge.
  • Forwarding Path: The best paths that are kept active to pass traffic.
  • Blocking / Discarding Path: Redundant links are put into a state where they listen for STP messages but do not forward regular data traffic. If the main link fails, STP will unblock the redundant link to restore connectivity.

A Simple Topology Example

      Switch A (Root Bridge)
       ↙       ↘
Switch B ————— Switch C

In this triangle topology, there is a physical loop. STP will elect Switch A as the Root Bridge. Switch B and Switch C both have direct links to the Root. To break the loop, STP will evaluate the link between B and C. One side of that link will be placed into a blocking state (preventing forwarding simultaneously under normal operation), effectively breaking the loop while keeping a backup path available.

Modern Variants: RSTP

While the original STP (802.1D) could take up to 50 seconds to converge after a topology change, modern networks use Rapid Spanning Tree Protocol (RSTP, 802.1w). RSTP operates on the same core concepts but can recover from failures in just a few milliseconds. It introduces newer terminology (like the Discarding state instead of Blocking/Listening), but the conceptual goal—loop prevention—remains identical.
