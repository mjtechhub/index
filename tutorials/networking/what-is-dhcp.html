What Is DHCP?

Beginner 5 min read

DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and network settings (like Subnet Mask and Default Gateway) to devices on a network.

How It Works (DORA)

  • Discover: Client broadcasts looking for a server.
  • Offer: Server offers an IP.
  • Request: Client requests the offered IP.
  • Acknowledge: Server confirms the lease.

Troubleshooting Tip

If your IP address starts with 169.254.x.x (APIPA), your device failed to reach the DHCP server.
