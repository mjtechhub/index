What Is a Default Gateway?

A Default Gateway is the device (usually a router) that traffic is sent to when the destination IP address is outside the local network (LAN).

Practical Example

When you want to talk to another computer in your house, your computer talks directly to it via the switch. When you want to talk to google.com, your computer sends the traffic to the Default Gateway (your home router) to be forwarded to the internet.
