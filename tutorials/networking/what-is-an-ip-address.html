What Is an IP Address?

Beginner 5 min read

An IP (Internet Protocol) address is a unique numerical label assigned to every device connected to a computer network that uses the Internet Protocol for communication.

IPv4 vs IPv6

IPv4 addresses look like 192.168.1.5. Because we ran out of IPv4 addresses, IPv6 was introduced, which looks like 2001:0db8:85a3:0000:0000:8a2e:0370:7334.

Related Command

Use ipconfig /all on Windows or ifconfig on Linux to check your IP.
