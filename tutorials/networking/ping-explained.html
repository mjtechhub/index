Ping Explained

Ping is a network utility used to test the reachability of a host on an IP network. It sends ICMP Echo Request packets and waits for an Echo Reply.

How to Use It

Open your command line and type ping google.com. If you get replies, you have internet connectivity. If you get Request timed out, the packet was lost or blocked by a firewall.
