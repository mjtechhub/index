What Is DNS?

Beginner 5 min read

DNS (Domain Name System) is the phonebook of the internet. It translates human-readable domain names (like google.com) into IP addresses (like 142.250.190.46) that computers use to connect to each other.

Troubleshooting Tip

If you can access websites by their IP address but not by their name, you have a DNS issue. Try changing your DNS server to 8.8.8.8.

Related Command

Use nslookup to troubleshoot DNS resolution.
